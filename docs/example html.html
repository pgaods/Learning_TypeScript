Quick Reference

Category Tags Use Case
Structural <header>, <nav>, <main>, <section>, <article>, <footer> Organize page layout
Containers <div>, <span> Group content for styling
Text <p>, <h1>-<h6>, <strong>, <em> Format text content
Lists <ul>, <ol>, <li> Organize items
Media <a>, <img>, <video>, <audio> Link and embed content
Data <table>, <tr>, <th>, <td> Display tabular data
